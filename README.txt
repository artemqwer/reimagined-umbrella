Бот: надішліть .zip — отримаєте фото й відео з нього. Архіви до 2 ГБ (з Telegram Premium — до 4 ГБ).

Змінні середовища:
  BOT_TOKEN          — токен від @BotFather
  TELEGRAM_API_ID    — з my.telegram.org -> API development tools
  TELEGRAM_API_HASH  — звідти ж

Потрібен постійний диск, змонтований у /var/data (10 ГБ).
Після запуску одразу напишіть боту /start — станете адміном.
Адмін: /invite — посилання-запрошення, /users — список, /kick ID — забрати доступ.
